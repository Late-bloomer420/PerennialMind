# PerennialMind
Features:  1. Growth Tracker: Set and track personal goals with a timeline feature to celebrate progress.  
2. Knowledge Hub: Curated articles, book summaries, and tutorials across various interests (coding, fitness, art, etc.).  
3. Community Corner: A forum where users can share their late-bloomer success stories, challenges, and tips.  
4. Daily Challenges: Encourages users to take small steps daily with bite-sized challenges.  
5. Reflection Journal: A digital journal for users to record thoughts, lessons, and personal milestones.
